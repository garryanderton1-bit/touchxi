# TouchXI

Your team. Your tactics. Your game.

A mobile-first grassroots football coaching and matchday app: squad and positions, fixtures, an automatic
rotation planner for fair playing time, a live matchday screen with clock, subs, injuries and alerts,
match reports and stats.

It is a Progressive Web App: open it in Safari or Chrome and use **Add to Home Screen**. After the first
visit it works offline. Team data is stored on the device only; use **Team › Copy backup** to keep a copy.

Hosted with GitHub Pages from the `main` branch.
